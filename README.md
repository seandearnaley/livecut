# Livecut Redux

Livecut Redux is the Human Being Audio live beat slicer, based on Remy Muller’s Livecut and Nick Collins’ BBCut.

[Download Livecut Redux for macOS, Windows and Ubuntu](https://humanbeingaudio.com/#livecut-redux) · [Source, build instructions and licence](https://github.com/seandearnaley/human-being-audio/tree/main/products/livecut-redux)

Development and releases moved to the Human Being Audio studio repository. This repository preserves the original project history.
