# Livecut 1.0 Suction Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The pad's Suction program: a squeezing, breathing, level-held band filter over gentle cutting.

**Architecture:**
- Impact's filter gains an engine-only `band` type: a high-pass into a low-pass, with smoothing and a level hold.
- The cutter resets its effect rack when it goes idle.
- `PadMapping` carries `ImpactParameters`, and Suction maps the pad onto them.

**Tech Stack:** C++20, JUCE 9.0.4, Catch2 3, CMake. Engine code stays JUCE-free.

**Spec:** `docs/superpowers/specs/2026-11-02-livecut-1.0-suction-design.md`. Parent: `docs/superpowers/specs/2026-11-01-livecut-1.0-pad-design.md`.

## Global Constraints

- **Classic is unchanged.** The `lowPass`, `bandPass` and `highPass` outputs are bit-identical to before. All existing tests, including `LegacyEquivalenceTests`, pass unchanged. The `impactFilterType` parameter keeps exactly its three choices.
- **Audio thread:** no allocation, locks or I/O. No new parameters.
- **Values verbatim from the spec:**
  - smoothing: 20 ms one-pole (edges in log frequency);
  - level followers: 150 ms RMS;
  - gain clamp: [−6, +18] dB;
  - gate: input follower above −80 dBFS;
  - crossed edges: high edge held one semitone above the low edge.
- **Style and process:** match the surrounding style (Allman braces, a space before call parentheses in `src/`) and SPDX headers. RED/GREEN for each behaviour. Commit per task, ending the message with your model's `Co-Authored-By` trailer.

## Review Focus

1. **Silence and very quiet input:** the level hold must never pump noise up. Test with a −90 dBFS input and with digital silence.
2. **Resonant peaks:** at `q` 2.5 with the edges close, output peaks stay finite and bounded. Test a sine at the edge frequency: output peak ≤ 4 × input peak.
3. **Extreme rates:** at 8 kHz and 384 kHz, the edges clamp below Nyquist and the output stays finite.
4. **Idle reset while Hold is latched:** a latched Hold never goes idle, so the rack keeps running and nothing resets mid-sound. Test in Task 2.
5. **Switching Suction to Cut while engaged:** the filter's wet ramps out over 2 ms at the next cut. Test that the maximum sample-to-sample step around the switch is no larger than in the same render with Cut throughout.

- [ ] **Step 1: Pin Classic first.** Before changing any code, add `"Classic filter types are bit-identical"`:

  - Hash the float output bits of each type (FNV-1a over the raw bytes).
  - Assert the three hashes. Paste them as literals, measured on the unchanged code.
  - It passes now and must keep passing.
- [ ] **Step 2: Write the failing tests:**
  - `"A band filter's edges are where it says"`: `q` 0.707, low 200, high 2000, at 48 kHz. The steady-state sine gain at 200 Hz and at 2000 Hz is −3 dB ±1 dB **before the level hold**. Run the gain-measurement sub-case with the hold's gain read from diagnostics and divided out, or expose the pre-hold output in a test seam named in the code. Gains at 50 Hz and 8 kHz are below −10 dB.
  - `"A band breathes open at each cut"`: with `envelopeOctaves` 1.5 and `decayMs` 180, the diagnostics' effective low edge right after `startCut` is lower, and its high edge higher, than 180 ms later.
  - `"A band holds its level"`: pink noise (Paul Kellet's filter on the local LCG), from fully open (30–18000) to squeezed (600–1500, `q` 2.5). After 500 ms, output RMS is within ±1.5 dB of input RMS.

  - `"A band's resonant peak stays bounded"`: Review Focus 2.
  - `"A band at extreme rates stays finite"`: Review Focus 3.
  - `"A band glides when its edges jump"`: render with the edges jumping 200/2000 → 1000/1200 mid-render. The largest sample-to-sample output step after the jump is no more than 1.5 × the largest step in the same render without the jump.
  - `"Crossed band edges hold a semitone apart"`: low 1000, high 900, so the effective high edge is 1000 × 2^(1/12).
