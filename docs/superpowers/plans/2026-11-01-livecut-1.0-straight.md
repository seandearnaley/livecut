# Livecut 1.0 Straight Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A pad switch, Straight, that keeps every cut on even divisions of the beat in Cut, Bounce and Glitch.

**Architecture:**
- A `straight` flag in the engine's `CutParameters` is honoured by CutProc11, Bounce and SQPusher. With it off, they're bit-identical to today.
- The pad sets the flag from a new `padStraight` parameter through `padSettings`.
- The editor adds a toggle.

**Tech Stack:** C++20, JUCE 9.0.4, Catch2 3, CMake. Engine code stays JUCE-free.

**Spec:** `docs/superpowers/specs/2026-11-01-livecut-1.0-straight-design.md`

## Global Constraints

- **Straight off is bit-identical.** With `straight == false`, every procedure makes exactly today's random draws and cuts. All existing tests, including `LegacyEquivalenceTests`, pass unchanged.
- **Straight on:** every cut's length in beats × 64 is a whole number, within 1e-9. The units-to-beats conversion is `beats = units * beatsPerBar / unitsPerBar`.
- **Parameter:** `padStraight` is "Pad Straight", a bool, default false, version hint 9, at index 113 directly after `surface`. No existing index, ID, range or choice changes.
- **Audio thread:** no allocation, locks or I/O.
- **Style and process:** match the surrounding style (Allman braces, a space before call parentheses in `src/`) and SPDX headers. RED/GREEN for each behaviour. Commit per task, ending the message with your model's `Co-Authored-By` trailer.

## Review Focus

1. **Truncation in Glitch:** with Straight on, SQPusher's truncation to the phrase end still yields only even divisions. Truncating at a unit boundary keeps even divisions on 8/16/32-unit grids. Test in Task 1.
2. **Bounce in 3/4 or 6/8:** with Straight on, Bounce still recovers the beat grid and never leaves a cut that isn't an even division. Test in Task 1 at `beatsPerBar` 3.
3. **Toggling mid-phrase** takes effect from the next block and never faults the processor. Test in Task 2.

### Task 1: Straight in the engine procedures

**Files:**
- Modify: `src/engine/Cut.h`, adding `bool straight = false;` to `CutParameters` with the comment "Every cut on even divisions of the beat".
- Modify: `src/engine/CutProc11.cpp`, `src/engine/Bounce.cpp`, `src/engine/SQPusher.cpp`.
- Test: `tests/engine/StraightTests.cpp` (new, tag `[straight]`), added to `LivecutEngineTests` in `CMakeLists.txt`.

**Interfaces:**
- Produces `CutParameters::straight`.

**Rules, verbatim from the spec:**
- **CutProc11:** when `params.straight`, the stutter roll chooses from `{1, 2, 4, 8}` cuts per unit with weights `{.4, .3, .1, .05}`, in one `random.weighted` draw.
- **Bounce:** when `params.straight`:
  - The ratchet is 8 cuts: 2 × `zone/4`, 2 × `zone/8`, 4 × `zone/16`. The pitch `step` is 0, 1, 2 for those three groups, and cents use the existing `100 * round (climb * step / 2)`.
  - The bounce move is `beat/4, beat/4, beat/2` when `even`, else `beat*3/4, beat/4`.
  - Everything else, including every `random.chance` call and its order, is unchanged.
- **SQPusher:** when `params.straight`, the fill is chosen as `straightFills[random.integer (0, 5)]`, where `straightFills = {0, 1, 2, 4, 9, 11}`.

- [ ] **Step 1: Write the failing tests** in `StraightTests.cpp`.
  - A helper `bool evenDivisions (const std::vector<Cut>&, int unitsPerBar, double beatsPerBar)` checks the 1/64-beat rule for every cut. Using `testing::playPhrase` from `EngineTestHelpers.h`, at 4/4 unless stated:
  - `"Straight Cut rolls only in even divisions"`: CutProc11 with `stutterChance` 1 and `stutterArea` 1, units per bar 8, 16 and 32, seeds 1–200.
  - `"Straight Bounce bounces and ratchets in even divisions"`: Bounce with `bounceChance` 1 and `ratchetChance` 1, units 16, seeds 1–200. Also at `beatsPerBar` 3 with units 12.
  - `"A straight ratchet climbs in three steps over eight cuts"`: the exact lengths and cents for `climb` 12, units 16.
  - `"Straight Glitch plays only even fills"`: SQPusher with activity .95, units 16 and 32, seeds 1–300.
  - `"Straight off leaves every procedure's cuts unchanged"`: for each procedure, the same seed with `straight` false and default params produces identical cut lists to a reference run of the same code path. Re-run the existing suites to confirm.
