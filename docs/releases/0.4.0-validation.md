## Scope of validation

Local Release bundles are ARM64 and are not installed into user plug-in folders
by this worker. CI must produce universal macOS/Windows artifacts and run normal
format validators, signing and notarisation. JUCE source inspection confirms
`std::isinf` maps to `Vst::kInfiniteTail` in the VST3 wrapper; AU's `GetTailTime`
forwards the processor's double tail time. This source inspection is not an AU
host-validator result.

No listening test or manual DAW Hold/groove/Capture/export/import result is claimed
here. Prior 0.3 manual playback/mix checks passed, but its editor was offscreen
and native Capture testing was blocked by TCC; that does not establish a manual
Capture pass for either version. The coordinating task records remaining manual
and packaged-release evidence separately.
