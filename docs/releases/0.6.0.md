# Livecut 0.6.0 — Impact

Impact adds three cut-driven wet effects: **Slice Filter, Drive/Wavefold and
Transient Shaper**. They follow the existing Crusher and Comb and feed Audio
Hold before global Wet/Output Trim. Final-output Capture and WAV export continue
to record the heard post-mix output.

## Cut envelopes, probability and repeats

The effects share cut onset and probability context. Filter and Drive share an
attack/decay envelope that retriggers on each actual cut onset, including swung
cuts. Attack ranges from 0 to 25 ms; Decay ranges from
5 to 1000 ms and specifies the time to reach -60 dB after the attack. A short cut
can retrigger the envelope before its previous decay completes. These are elapsed
audio-time controls, so a tempo edit does not stretch a decay already in progress.

Each effect has its own enable, Chance and Mix controls. Chance is selected once
per cut from the saved seed, phrase position, block position, cut identity and a
different fixed tag for each effect. Zero Chance selects no cuts; full Chance
selects every cut. Enabling an effect or changing its Chance does not consume
the legacy pattern generator's random draws or change Crusher/Comb settings.

Filter Repeat moves the cutoff by up to four octaves in either direction across
the block's cuts. Drive Repeat moves the drive by up to 24 dB in either direction.
The first cut has zero repeat offset and the last reaches the requested offset;
a single-cut block has zero repeat offset. Envelope and repeat modulation sum
before the effective frequency/drive limits apply.

Impact settings are captured when a block is planned, then remain fixed for
that block's repeats. A queued swung block keeps its original settings. Controls
therefore take effect with the next newly planned block. Enable/Chance transitions
use a short wet transition rather than switching the audio abruptly.

## Slice Filter

Slice Filter is a stereo-linked, two-pole state-variable filter with Low-pass,
Band-pass and High-pass modes. Cutoff ranges from 30 Hz to 18 kHz, Q from 0.5 to
8, and Envelope from -6 to +6 octaves. The effective cutoff cannot exceed 45% of
the processing sample rate. Both channels use the same modulation while retaining
separate audio state. Higher Q can raise levels around the cutoff; no hidden
output limiter replaces that response.

The filter follows Andrew Simper's [trapezoidal state-variable filter equations](https://cytomic.com/files/dsp/SvfLinearTrapOptimised2.pdf).
It needs no lookahead or additional audio buffer delay. Its frequency-dependent
phase response is part of the effect.

## Drive and Wavefold

Drive supplies smooth tanh saturation; Wavefold folds the signal with a smooth
sine transfer curve. Drive ranges from 0 to 30 dB, with an additional envelope
offset of -24 to +24 dB and repeat offset of -24 to +24 dB. The effective drive
remains inside the declared drive range. Enabled Drive at 0 dB is still nonlinear;
use its enable or zero Mix for a neutral path.

Both modes use first-order antiderivative antialiasing with double-precision
intermediate calculations and a DC blocker. This reduces aliasing; it does not
remove aliasing or make the wet path sample-exact with dry audio. ADAA introduces
a half-sample small-signal group delay and high-frequency attenuation. There is
no lookahead, oversampling switch or additional integer buffer delay. See the
[original ADAA paper](https://dafx.de/paper-archive/2016/dafxpapers/20-DAFx-16_paper_41-PN.pdf)
and [official Faust implementation notes](https://faustlibraries.grame.fr/libs/aanl/).

## Transient Shaper

Transient Shaper follows stereo-linked fast and slow envelopes of the incoming
rack audio. Attack and Sustain each range from -18 to +18 dB; Time ranges from
10 to 200 ms. It changes actual audio dynamics rather than substituting a fixed
gain pulse for transient detection. Both gains at zero leave its audio unchanged.
It needs no lookahead or additional buffer delay.

## Existing sessions and latency

Every new effect defaults to off. Existing parameter IDs, order, ranges, version
hints and defaults remain intact. New controls append with version hint 6 and
state schema 6; the legacy algorithm version remains 2. Loading an older state
also resets Impact controls to their defaults when the receiving instance had
already adjusted them. Effect state and envelope phases are transient.

With Impact disabled, the existing cut/effect audio path and legacy randomness
remain unchanged. Live retains zero declared buffer latency; Studio retains its
fixed 500 ms delay. Studio applies Impact settings from the delayed audio's
original context. Normal release/prepare cycles retain the configured latency
declaration, preserving the 0.5.1 host-restart correction.

## Validation status

This document describes the implementation contract. Automated DSP/integration,
state/UI, wrapped plug-in, platform CI and native host results must be recorded
before the release is claimed complete. Numerical fixtures and native rendering
can establish measured behavior; they do not constitute a subjective listening
assessment. Publication remains with the repository owner.

### Existing swung gate-rounding limit

Impact preserves the 0.5.1 gate scheduler. A diagnostic fixture at 8 kHz with
75% Swing, a 120→80 BPM edit at frame 10,000 and a later seek found a pre-existing
rounding difference when the host supplies different buffer/PPQ context edges.
At frame 11,637 the legacy sounding budget is 188 frames for one-frame contexts
and 187 for 7-, 137- or 512-frame contexts. A half-sample deadline crosses the
rounding boundary as host position arithmetic changes. Impact's cut count,
chance decisions and envelope samples remain identical across those contexts.

In this fixture the maximum stereo sample difference with Impact off is
approximately 0.024802 over 81 or 96 frames. Active stateful effects extend that
input difference; this fixture measured approximately 0.059636 over 4041 or 4183
frames. These are fixture measurements, not universal bounds. There is no claim
that complete audio is bit-identical across arbitrary host PPQ partitions.

Audio remains bit-identical when the same original render contexts are split
across different output buffers. That contract and the separate per-frame
Impact modulation schedule are tested exactly. Changing the historical gate
rounding needs an explicit compatibility decision outside this FX release.
