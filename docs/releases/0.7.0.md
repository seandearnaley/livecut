# Livecut 0.7.0 — Fracture

Fracture adds **GrainCut, TapeCut and Ring / Frequency Shift**. A new Family
selector chooses Classic, GrainCut or TapeCut. Classic retains the original
four procedures and their host automation mapping. Family changes take effect
at the next bar; the other Fracture settings are captured when a block is planned.

## GrainCut

GrainCut reads a fixed pool of retained audio with up to eight prepared voices.
Grain Size spans 10–160 ms, Density 0.5–4, Position Spread 0–250 ms, Pitch Spread
0–1200 cents and Pan Spread 0–100%. Activity chooses one, two or four outer cuts
per beat. The outer cuts trigger the shared effects envelope and probability;
individual grains do not retrigger them. Common pitch combines with grain pitch
variation, for a bounded playback-rate range of 1/8× to 8×.

Each admitted cut keeps an immutable source pool in the same transport epoch.
Live playback shows **Waiting** and supplies zero grain wet audio until the full
pool, including interpolation guards, exists. Global dry audio remains available.
If the musical gate ends first, that cut is cancelled. The reader does not shorten
the pool or substitute Classic playback. Startup duration depends on the settings
and sample rate; it is not an added declared host latency. Live and Studio may
therefore differ during initial source admission.

Grains use Hann windows and overlap normalization by the larger of one or the
summed window weights, with an outer cut taper of at least 2 ms. A prepared
finite-support resampler uses conservative rate buckets and interpolated phases.
Its tested high-rate folded-tone rejection exceeds 50 dB relative to linear
interpolation in the specified fixture; this is not an alias-free guarantee.
Coefficient generation and storage allocation happen during preparation.

## TapeCut

TapeCut integrates a discrete speed trajectory into the source read position.
Start and End Speed each span 0–1×. Linear and Smooth curves run over a half,
one, two or four beats. Alternate swaps the endpoints on successive outer cuts,
including across phrase boundaries; a transport reset restarts that sequence.
Tape speed replaces common pitch for this family, and the editor disables the
common Pitch controls while TapeCut is selected.

Zero speed is a true stop. A square-root speed gain reaches silence at zero
instead of holding a DC sample. A tempo edit preserves the current read position
and speed while retargeting the remaining causal trajectory. Reverse and Attack
Align require a complete eligible source span and retain their frozen trajectory
budget. An extension beyond that budget reports **Transform budget exhausted**
and supplies zero Tape wet audio, rather than reading outside the admitted span.

## Ring / Frequency Shift

This effect works with all three families after Impact and before Audio Hold,
global Wet/Output Trim and final-output Capture. It has independent Enable,
Chance and Mix controls. Chance uses a distinct tagged cut identity and consumes
no legacy pattern RNG draws. Rate, Envelope and Repeat each span ±2000 Hz;
their combined rate is clamped to that same range. Envelope uses the existing
cut attack/decay clock, and Repeat progresses across the block's outer cuts.

Ring produces both modulation sidebands; the sign of its rate does not change
the sound. Frequency Shift uses a quadrature network to approximate single-sideband
translation, with signed rates choosing upward or downward translation. Measured
image rejection exceeds 60 dB at the test probes across 8–384 kHz. This does not
establish that rejection at every frequency, during modulation or at startup.

The quadrature allpass network has frequency-dependent phase/group delay but no
additional declared buffer latency. Shifting DC can add approximately 3 dB,
and translations crossing Nyquist alias. Neither mode includes a hidden limiter.
Two-millisecond transitions smooth selection, mix, mode and rate changes; the
oscillator and quadrature state continue through muted intervals. Settled zero
combined rate returns exact dry audio, rather than a phase-coloured zero shift.

## Compatibility, display and validation

The original 69 parameter declarations remain unchanged. Nineteen new controls
append with version hint 7 and state schema 7; the legacy algorithm remains
version 2. Classic selected and Frequency disabled are the defaults, including when an
older state is loaded into a previously adjusted instance. Grain voices, tape
position and oscillator/filter history are transient processing state.

Live retains zero declared buffer latency; Studio retains 500 ms and renders
settings from the delayed audio's original context. Hold receives the processed
wet audio and Capture receives the final mix. The editor exposes family, waiting,
voice count, tape speed and explicit source/budget/context failures. Pending
family changes are distinguished from the family currently playing.

The inherited swung gate-rounding limit described in the [0.6 contract](0.6.0.md)
remains unchanged. Exact audio is required when the same original contexts are
split across output buffers; there is no claim of bit identity across arbitrary
host PPQ partitions.

Automated regression, numerical DSP, allocation, state/UI, actual wrapped VST3,
sanitizer, platform CI and exact-package native checks are separate release gates.
This document specifies behavior; final release notes record their completed
results and limitations. Publication remains with the repository owner.
